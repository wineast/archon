GMCC Hermes 核保标准 – 加州（CA）物业专用

1. Transaction Type（交易类型）
合格：Purchase（适用于全部四种收入证明方式：Alt Doc、ABIO、3MB、BBS）、Rate & Term Refinance。
Cash-Out Refinance：仅 Alt Doc 收入证明方式合格，ABIO、3MB、BBS 均不支持现金再融资。
Delayed Financing：视为现金再融资，适用现金再融资全部规则（仅 Alt Doc 合格）。

2. Occupancy Type（居住类型）
合格：Primary Residence、2nd Home（含外国国民）、Investment（含外国国民）。
限制：外国国民（Foreign National）不得使用主要居所，仅限第二居所或投资物业。

3. Property Type（房产类型）
合格：SFR / PUD、2-4 Units、Warrantable Condo。
不合格：Non-Warrantable Condo。

4. Citizenship/Residency Status（身份状态）
US Citizen：合格。
Green Card（永久居民）：合格。
Visa Type（工作签证）：合格签证类型包括 H1b、O、L 等有效工作签证。
F1 Visa with EAD / F1 Visa without EAD：仅当 EAD 类型为 C08 时合格（F1 学生工卡）。其他 F1 及 F2 签证（无论是否持有 EAD）均不合格。
EAD Type（工卡）：仅 C08 类 EAD 合格，其他基于 F1/F2 等的 EAD 均不合格。
Foreign National（外国国民）：仅限 Alt Doc 收入证明方式，不支持 ABIO、3MB、BBS。仅限 Second Home 或 Investment 占用类型，Primary Residence 不允许。文件要求：有效护照、签证、I-94（F1/F2 不接受）；免签计划（ESTA）需护照及 I-94W 或 ESTA 批准证明。信用报告：如有 SSN/ITIN 须拉取美国信用报告；如无 SSN/ITIN 无需信用报告，但需确认无负面记录。借款上限：同一外国国民借款人 ≤ 2 笔贷款，合计总额 ≤ $5,000,000。
ITIN：根据借款人实际居民身份归类——若为美国公民、绿卡、合格工作签证持有人，则适用对应身份规则；若实际为外国国民，则适用外国国民规则。
无信用记录（No Credit History）：即使为美国居民，仅能按外国国民项目规则申请（仅 Alt Doc、仅第二居所/投资、60% LTV、6 个月储备金等）。

5. Lien Position（抵押顺位）
合格：1st Mortgage。
不合格：2nd Mortgage。

6a. Loan Amount（贷款金额）
SFR / PUD / 2-4 Units：最高 $4,000,000。
Condominium：最高 $2,000,000（无论收入证明方式）。
超过 $2,500,000 且 ≤ $4,000,000：须经投资者银行事先批准，并支付 $750 承保费。
若贷款金额 > $4,000,000 或公寓 > $2,000,000：不合格。

6b. LTV（贷款价值比）
LTV 计算基数：购买交易取购买价与评估价之较低者；再融资取评估价。

Alt Doc（替代文件）收入方式：
SFR / PUD / 2-4 Units：贷款额 ≤ $3,000,000 最大 LTV = 75%；贷款额 $3,000,001 - $4,000,000 最大 LTV = 70%。
Condominium（贷款额 ≤ $2,000,000）：最大 LTV = 70%。
Foreign National（仅 Alt Doc）：贷款额 ≤ $4,000,000 最大 LTV = 60%（适用于 1-4 单元及公寓）。
Cash-Out Refinance：LTV 上限受限于上述物业类型及外国国民 LTV 上限，无独立更高 LTV。

ABIO / 3MB / BBS 收入方式：
SFR / PUD / 2-4 Units：贷款额 ≤ $3,000,000 最大 LTV = 75%；贷款额 $3,000,001 - $4,000,000 最大 LTV = 70%。
Condominium（贷款额 ≤ $2,000,000）：最大 LTV = 70%。
Foreign National：ABIO / 3MB / BBS 均不支持外国国民，无 LTV 适用。
Cash-Out Refinance：ABIO / 3MB / BBS 均不支持现金再融资，无 LTV 适用。

若用户输入的 LTV 超过对应条件下最大 LTV，则不合格。

7a. Property State（物业所在州）
合格州：仅加利福尼亚州（CA）。任何其他州不合格。

7b. Street Address（街道地址）
不直接用于核保判断，仅用于确认物业位于加州境内。

8. Credit FICO Score（信用分数）
分数选取规则：提供 2 个分数取较低者，3 个分数取中间值。
Alt Doc 收入方式：SFR / PUD / 2-4 Units 贷款额 ≤ $3,000,000 最低 FICO >= 680；贷款额 $3,000,001 - $4,000,000 最低 FICO >= 720；Condominium（贷款额 ≤ $2,000,000）最低 FICO >= 700。
ABIO / 3MB / BBS 收入方式：SFR / PUD / 2-4 Units 贷款额 ≤ $3,000,000 最低 FICO >= 680；贷款额 $3,000,001 - $4,000,000 最低 FICO >= 720；Condominium（贷款额 ≤ $2,000,000）最低 FICO >= 700。
Foreign National：不要求 FICO 分数。
若用户输入的 FICO 低于对应条件下最低要求，则不合格。

9. Income Type（收入类型）
GMCC Hermes 仅支持以下收入证明方式，客户所选收入类型必须与之一致，否则不合格。

与 Alt Doc 匹配的收入类型：
NQM -WVOE：合格。
NQM-Borrower Prepared P&L：合格。
NQM-CPA Prepared P&L：合格（自雇，所有权 >= 25%）。

与 ABIO / VVOE 匹配的收入类型：
NQM-VVOE：合格（受薪员工或自雇，所有权 >= 25%）。

与 3 个月个人银行流水（3MB）匹配的收入类型：
NQM-3mo Personal Bank Statement：合格。

与 6 个月商业银行流水（BBS）匹配的收入类型：
客户选项中没有直接对应项（NQM 12/24mo Bank Statements 不支持）。若客户选择银行流水类，仅上述 NQM-3mo Personal Bank Statement 合格；Hermes 不接受 12 个月或 24 个月银行流水。

以下收入类型均不合格（与 Hermes 收入证明方式不兼容）：Full Doc - W2 Wage Earner、NQM - 1year of 2-years Full Doc-Self-employed、No Ratio - No Job/No DTI- DTA、NQM 12/24mo Bank Statements、NQM - 1-2yr 1099、NQM-DSCR、No Ratio - Asset Depletion/Utilization、NQM - ATR In Full。
