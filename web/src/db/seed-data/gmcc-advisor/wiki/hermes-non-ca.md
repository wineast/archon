GMCC Hermes 核保标准 – 非加州（AZ, CO, DC, GA, IL, NJ, NY, NV, TX, VA, WA）物业专用

1. Transaction Type（交易类型）
合格：Purchase（适用于全部四种收入证明方式：Alt Doc、ABIO、3MB、BBS）、Rate & Term Refinance（适用于全部四种收入证明方式，申请时物业不得挂牌出售，已挂牌须在申请日前撤销）。
Cash-Out Refinance：仅 Alt Doc 收入证明方式合格，ABIO、3MB、BBS 均不支持现金再融资。
Delayed Financing：视为现金再融资，适用现金再融资全部规则（仅 Alt Doc 合格、6 个月产权持有期等）。

2. Occupancy Type（居住类型）
合格：Primary Residence、2nd Home（含外国国民）、Investment（含外国国民）。
限制：外国国民（Foreign National）不得使用主要居所，仅限第二居所或投资物业。

3. Property Type（房产类型）
合格：SFR / PUD、2-4 Units、Warrantable Condo。
不合格：Non-Warrantable Condo。

4. Citizenship/Residency Status（身份状态）
US Citizen：合格。
Green Card（永久居民）：合格。
Visa Type（工作签证）：合格。
F1 Visa with EAD / F1 Visa without EAD：仅当 EAD 类型为 C08 时合格（F1 学生工卡）。其他 F1 及 F2 签证（无论是否持有 EAD）均不合格。
EAD Type（工卡）：仅 C08 类 EAD 合格，其他基于 F1/F2 等的 EAD 均不合格。
Foreign National（外国国民）：仅限 Alt Doc 收入证明方式，不支持 ABIO、3MB、BBS。仅限 Second Home 或 Investment 占用类型，Primary Residence 不允许。文件要求：有效护照、签证、I-94（F1/F2 不接受）；免签计划（ESTA）需护照及 I-94W 或 ESTA 批准证明。信用报告：如有 SSN/ITIN 须拉取美国信用报告。

5. Lien Position（抵押顺位）
合格：1st Mortgage。
不合格：2nd Mortgage。

6a. Loan Amount（贷款金额）
SFR / PUD / 2-4 Units：最高 $2,500,000。
Condominium：最高 $2,000,000（无论收入证明方式）。
超过 $2,500,000 或公寓 > $2,000,000：不合格。

6b. LTV（贷款价值比）
LTV 计算基数：购买交易取购买价与评估价之较低者；再融资取评估价。

Alt Doc（替代文件）收入方式：
SFR / PUD / 2-4 Units：贷款额 ≤ $2,000,000 最大 LTV = 75%；贷款额 $2,000,001 - $2,500,000 最大 LTV = 70%。
Condominium（贷款额 ≤ $2,000,000）：最大 LTV = 70%。
Foreign National（仅 Alt Doc）：贷款额 ≤ $2,500,000 最大 LTV = 60%（适用于 1-4 单元及公寓）。
Cash-Out Refinance：LTV 上限受限于上述物业类型及外国国民 LTV 上限，无独立更高 LTV。

ABIO / 3MB / BBS 收入方式：
SFR / PUD / 2-4 Units：贷款额 ≤ $2,000,000 最大 LTV = 70%；贷款额 $2,000,001 - $2,500,000 最大 LTV = 65%。
Condominium（贷款额 ≤ $2,000,000）：最大 LTV = 70%。
Foreign National：ABIO / 3MB / BBS 均不支持外国国民，无 LTV 适用。
Cash-Out Refinance：ABIO / 3MB / BBS 均不支持现金再融资，无 LTV 适用。

若用户输入的 LTV 超过对应条件下最大 LTV，则不合格。

7a. Property State（物业所在州）
合格州：亚利桑那州（AZ）、科罗拉多州（CO）、华盛顿哥伦比亚特区（DC）、乔治亚州（GA）、伊利诺伊州（IL）、新泽西州（NJ）、纽约州（NY）、内华达州（NV）、德克萨斯州（TX）、弗吉尼亚州（VA）、华盛顿州（WA）。
任何其他州（含加州）：不合格。

7b. Street Address（街道地址）
不直接用于核保判断，仅用于确认物业位于上述合格州。

8. Credit FICO Score（信用分数）
Alt Doc 收入方式：贷款额 ≤ $2,000,000 最低 FICO >= 680；贷款额 $2,000,001 - $2,500,000 最低 FICO >= 700。
ABIO / 3MB / BBS 收入方式：统一最低 FICO >= 700（无论贷款额、物业类型）。
Foreign National：不要求 FICO 分数。
若用户输入的 FICO 低于对应条件下最低要求，则不合格。

9. Income Type（收入类型）
合格收入类型（与 Hermes 四种收入方式匹配）：NQM -WVOE、NQM-Borrower Prepared P&L、NQM-CPA Prepared P&L、NQM-VVOE、NQM-3mo Personal Bank Statement。
以下收入类型均不合格（与 Hermes 收入证明方式不兼容）：Full Doc - W2 Wage Earner、NQM - 1year of 2-years Full Doc-Self-employed、No Ratio - No Job/No DTI- DTA、NQM 12/24mo Bank Statements、NQM - 1-2yr 1099、NQM-DSCR、No Ratio - Asset Depletion/Utilization、NQM - ATR In Full。
