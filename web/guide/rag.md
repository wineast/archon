# RAG（检索增强生成）

RAG 模块让 Agent 能基于上传的文档进行语义搜索，在对话中引用文档内容回答用户问题。

## 功能概述

- **文档上传**：支持 PDF、TXT、DOCX 格式，最大 10MB
- **自动分块**：上传后自动将文档切分为语义片段并生成向量嵌入
- **语义搜索**：Agent 运行时自动注入 `rag_search` 工具，基于用户问题检索相关片段
- **可配置**：支持选择 Embedding 模型、调整分块参数和返回数量

## 使用步骤

1. 在 Build 页面找到 **RAG** 标签页
2. 点击 **启用** 按钮开启 RAG 功能
3. 在 **Documents** 标签页上传文档
4. 等待文档处理完成（状态变为 Ready）
5. Agent 对话时会自动调用 `rag_search` 检索相关内容

## 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| Embedding 模型 | 用于生成向量嵌入的模型 | `openai/text-embedding-3-small` |
| 分块大小 | 每个文档片段的目标字符数 | 500 |
| 重叠量 | 相邻片段之间的重叠字符数 | 50 |
| Top K | `rag_search` 默认返回的片段数量 | 5 |

## rag_search 工具

RAG 启用后，Agent 运行时会自动获得 `rag_search` 工具：

- **参数**：`query`（搜索文本）、`topK`（可选，覆盖默认值）
- **返回**：匹配的文档片段列表，包含内容、来源文档名、相似度分数

## 支持的文件格式

- **PDF**（`.pdf`）：提取纯文本内容
- **纯文本**（`.txt`）：直接使用
- **Word 文档**（`.docx`）：提取纯文本内容

## 注意事项

- 更换 Embedding 模型后，已有文档的向量不会自动更新，建议删除后重新上传
- 文档处理是同步的，大文件可能需要较长时间
- 分块会在句子边界切分，避免截断语句
