# 分润模式

FDE（前沿部署工程师）从合作企业内部孵化，通过**收益分成协议**激励，不涉及公司股权。

---

## 核心机制

- **角色制**：分润与 FDE 角色绑定，不与具体个人绑定。人员更替时分润自动转移给接任者
- **分润池**：每个 Agent 产生的收入按固定比例分配，不是公司股权
- **企业内部孵化**：FDE 来自客户企业内部，天然了解业务场景，零招聘成本

## 组织结构

```
Archon 平台
  └── 城市合伙人
        └── 企业 FDE
              └── 部署的 Agent → 产生收入 → 按比例分润
```

## 分润比例

| 收入类型 | FDE | 城市合伙人 | 平台 |
|---------|-----|-----------|------|
| Agent 部署服务费 | 30% | 10% | 60% |
| 月度 Token 用量费 | 15% | — | 85% |

> 比例为初始方案，可根据市场反馈调整。

## FDE 管理规则

### 准入

- 通过平台培训 + 考核认证后上岗
- 签署收益分成协议（非股权协议）
- 签署竞业/排他条款，不得同时代理竞品平台

### 活跃度要求

- 每季度至少维护 N 个活跃 Agent（具体数值待定）
- 低于最低活跃度，角色自动释放

### 退出

- FDE 离开 → 分润权转移给接任者
- 无历史分润追溯，仅当期生效

## 收费模型对照

分润模式嵌套在平台整体收费模型的三个阶段中：

| 阶段 | 平台收费 | FDE 分润来源 |
|------|---------|-------------|
| 早期 | FDE 人天服务费（卖服务） | 服务费提成 |
| 中期 | + 按 Agent 数量收费（卖平台） | 部署费提成 |
| 后期 | + 按对话/Token 用量收费（卖用量） | 用量费提成 |

## 合规要点

- 对外用"收益分成"、"业绩提成"，**不用"股份"一词**，避免非法集资风险
- 签分润协议而非股权协议——灵活、合规、可随时调整
- 城市合伙人层级可视情况给予少量期权，需单独走股权激励流程
