# v0.4.0 发布文案

## 短文案（朋友圈/Twitter）
Archon v0.4.0：Agent 的"创造力"终于可以自己调了。温度滑块上线，从精准回答到天马行空，一拖搞定。

## 长文案（公众号/小红书）
之前配置 Agent 的时候，模型温度是固定的，想让 Agent 回答更稳定或更有创意，没法直接调。

这次更新加了温度滑块控件——在 Agent 构建页的 Model Config 里，拖一下就能设定 AI 回答的"确定性"。0 是严格按套路来，2 是放飞自我，默认 0.3 偏稳定，适合大多数业务场景。

另外 Admin 面板也加了搜索功能，任务多了终于不用一页页翻了。
