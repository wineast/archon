# v0.4.0 发布演示脚本

> 预估时长：2 分钟
> 风格：产品更新演示

---

## P1: 封面（~10s）

**画面**：Archon v0.4.0 — 温度控制，让 Agent 听你的

**口播**：大家好，这次 v0.4.0 更新主要是一个实用的小功能——模型温度控制滑块，让你能直观地调整 Agent 回答的风格。

---

## P2: 本次更新概览（~15s）

**画面**：
- 温度 Slider 滑块控件
- 默认温度调整为 0.3
- Admin 任务搜索

**口播**：这次有三个更新点：温度滑块让你可视化调温度，默认温度从 0.7 降到了 0.3 更稳定，还有 Admin 面板加了搜索。

---

## P3: 温度 Slider 控件（~45s）

**画面**：[演示录屏] 从 Agent 构建页 → Model Config 开始

**口播**：之前配置模型的时候，温度只有一个数字输入框，不太直观。现在加了滑块，左边是 0 最精准，右边是 2 最有创意，拖着调就行。输入框和滑块是联动的，你也可以直接打数字。

**操作步骤**：
1. 进入任意 Agent 的构建页
2. 点击左侧 Model Config
3. 选择一个已有的配置
4. 展示 Temperature 区域的 Slider + 数字输入框
5. 拖动 Slider 到不同位置，观察数字联动变化
6. 在输入框中直接输入 1.5，观察 Slider 位置变化

---

## P4: 默认温度 0.3（~20s）

**画面**：[演示录屏] 新建一个 Model Config

**口播**：另外我们把新建配置的默认温度从 0.7 降到了 0.3。0.3 更适合需要稳定回答的业务场景，比如客服、数据提取这类。当然你随时可以自己调高。

**操作步骤**：
1. 点击 New Config 按钮
2. 填入 Key 和 Name
3. 点击 Create
4. 展示新配置的温度默认值为 0.3

---

## P5: Admin 搜索 + 修复项（~15s）

**画面**：文字列表
- Admin 面板任务搜索
- Vercel 构建条件修复

**口播**：Admin 面板加了搜索框，可以按标题、标签、工作区快速找任务。另外修了一个构建配置的小问题。

---

## P6: 结尾（~10s）

**画面**：Archon — 让 AI 落地更简单

**口播**：以上就是 v0.4.0 的更新，温度控制虽然是个小功能，但对调教 Agent 的回答风格很实用。下个版本见。
