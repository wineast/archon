## P3: 评估结果工具输出（~60s）

**画面**：[演示录屏] 从 Agent 构建页 → Evaluate tab 开始

**口播**：之前跑完评估，看到 Agent 调用了工具，但输出内容是看不到的，只能看到调用了什么工具、传了什么参数。现在点开评估结果，每个工具调用下面会直接展示返回值。比如 Agent 查了一个知识库，返回了哪些文档、匹配度多少，全部透明。这对调优 Agent 的工具使用策略特别有帮助。

**操作步骤**：
1. 进入 Agent 的构建页，点左侧 "Evaluate" tab
2. 选择一个已有的评估用例，点 "Run All" 执行
3. 等运行完成，点击某个结果卡片展开
4. 在工具调用区域，展示新增的 "Output" 折叠面板
5. 点击展开，查看工具返回的完整 JSON 数据

## P4: 安全增强速览（~30s）

**画面**：文字列表
- 版本发布/回滚需要 Agent 所有权验证
- 工具和函数测试需要编辑者权限
- Agent 导入支持大文件（100MB）
- Wiki 数据按 Agent 隔离
- 数据集查询按版本隔离

**口播**：安全方面做了五项加固。版本发布和回滚现在会检查你是不是这个 Agent 的所有者；工具测试不再是匿名可用的，需要编辑权限；导入功能支持了大文件上传，最大 100MB；另外 Wiki 和数据集的查询都做了严格的隔离，不会跨 Agent 或跨版本泄漏数据。
