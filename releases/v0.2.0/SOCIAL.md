# v0.2.0 发布文案

## 短文案（朋友圈/Twitter）

Archon v0.2.0：评估结果现在能看到工具调用的完整输出了，Agent 的每一步推理都透明可追溯。同时补齐了核心模块的 1300+ 测试守护和 5 项安全加固。

## 长文案（公众号/小红书）

**终于能看到 Agent 用工具做了什么了**

做 Agent 调优的时候最头疼的事情之一：跑完评估，看到 Agent 调用了工具，但输出是什么？不知道。只能猜。

v0.2.0 解决了这个问题——评估结果页面现在会完整展示每次工具调用的返回值。Agent 查了什么数据、算了什么结果、拿到了什么回复，一目了然。调优效率直接翻倍。

**更安全、更可靠**

这个版本我们还做了一轮安全加固：版本发布需要身份验证、工具测试需要权限校验、数据查询做了严格隔离。同时，聊天核心链路、消息持久化、Agent 导入导出三个关键模块补齐了 1300+ 项自动化测试，确保每次更新都有兜底。

**基础设施升级**

新增了 Admin 管理面板和版本对比查看器，开发运维体验大幅提升。工作流自动化也做了全面升级，从需求到发布的全链路都有对应的自动化技能支撑。
