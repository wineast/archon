## P3: 安全修复 — 数据隔离（~45s）

**画面**：[代码对比] 修复前后的数据查询逻辑

**口播**：之前有个问题——Agent A 的工具函数可以通过 wiki.search 读到 Agent B 的知识库内容。这在多客户场景下是致命的。现在每个查询都加了版本 ID 过滤，Agent 只能看到自己版本的文档。版本发布接口也加了归属校验，防止越权操作。工具测试端点增加了权限检查，未授权用户无法执行代码。这三个修复都有对应的单元测试守护，防止回归。

**要点**（文字列表即可）：
1. Wiki 查询加了 versionId 过滤 → Agent 间数据完全隔离
2. 版本发布加了 agentId 归属校验 → 防止跨 Agent 越权
3. 测试端点加了授权检查 → 杜绝未授权代码执行

---

## P4: Admin 管理面板（~60s）

**画面**：[演示录屏] 从终端启动 `make admin`

**口播**：之前管理工作区、看报告、做分支操作都要在终端里敲命令，现在有了可视化的 Admin 面板。启动一个命令就能打开浏览器，所有任务一目了然。可以看到每个任务的状态、展开查看链路报告、做分支对比、直接在页面上操作合并。

**操作步骤**（录屏时照做）：
1. 终端执行 `make admin`
2. 浏览器自动打开管理面板
3. 展示任务列表 — 点击展开一个已完成的任务
4. 展示报告 Tab — 切换查看缺陷报告、修复报告、验证报告
5. 展示分支对比 — 点击 Diff 查看变更内容
