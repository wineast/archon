# v0.1.0发布文案

## 短文案（朋友圈/Twitter）

Archon v0.1.0正式发布！修复了 3 个关键安全漏洞，Agent 之间的数据现在完全隔离。同时上线了 Admin 管理面板和完整的自动化工作流，从问题诊断到发布上线全链路覆盖。

## 长文案（公众号/小红书）

**你的 AI Agent 数据安全吗？**

在做安全审计时，我们发现了一个严重问题：一个 Agent 的工具竟然能读取另一个 Agent 的知识库内容。这意味着如果你为不同客户各创建了一个 Agent，它们的数据是互通的——客户 A 的 Agent 有可能看到客户 B 的商业资料。

这次更新，我们彻底修复了 3 个 P0 级安全漏洞：

1. **数据隔离** — 每个 Agent 只能访问自己的知识库文档，跨 Agent 读取被完全阻断
2. **版本越权** — 版本发布接口增加了归属校验，防止恶意操作
3. **代码执行** — 工具测试功能增加了权限检查，杜绝未授权的代码运行

除了安全加固，我们还带来了两个实用工具：

**Admin 管理面板** — 在本地启动一个可视化的任务管理界面，可以看到每个工作区的进度、查看报告、执行分支操作，再也不用在终端里敲一堆命令了。

**一键发布流程** — 输入一个命令，自动完成集成检查 → 发布验证 → PR 创建 → 合并 → 归档的完整流程。之前需要手动执行十几步的发布操作，现在一条命令搞定。

另外还修了几个影响使用的 Bug：对话中的链接现在能正确点击了、Agent 导入不再报错、新建对话时流式响应恢复正常。
