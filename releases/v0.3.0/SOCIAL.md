# v0.3.0 发布文案

## 短文案（朋友圈/Twitter）
Archon v0.3.0：修复了评测运行中途切换版本导致结果不准的问题。现在每次评测都锁定当前版本配置，结果 100% 可复现。

## 长文案（公众号/小红书）
你有没有遇到过这种情况：跑了一轮 Agent 评测，中途去改了一下配置，结果发现部分测试用例用的是新配置、部分用的是旧配置，最终评测结果怎么看都对不上？

这就是 v0.3.0 解决的问题。

之前点击"Run All"后，如果你在评测运行期间发布了 Agent 新版本或切换了编辑版本，后面还没跑到的测试用例会自动用新版本的工具和数据，但提示词还是旧版的——两套配置混着跑，结果自然不可信。

现在，评测启动的瞬间会锁定当前版本。无论你后续怎么改配置、发新版，正在运行的评测始终用同一套完整配置执行。每个 case 的结果都来自同一个版本快照，评测结论真正可靠。
