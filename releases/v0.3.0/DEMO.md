# v0.3.0 发布演示脚本

> 预估时长：2 分钟
> 风格：产品更新演示（Bug 修复专场）

---

## P1: 封面（~10s）

**画面**：Archon v0.3.0 / 评测配置一致性修复

**口播**：大家好，v0.3.0 是一个稳定性修复版本，解决了评测运行时配置漂移的问题。

---

## P2: 问题回顾（~20s）

**画面**：
- 发起评测 → 运行期间切换版本 → 结果不一致
- 示意图：Case 1 用 V1 配置，Case 5 用 V2 配置

**口播**：之前如果你在评测跑到一半的时候修改了 Agent 配置或者发布了新版本，后面还没执行的 case 会偷偷用上新版本的工具和数据，但提示词还是旧版的。这意味着同一次评测里不同 case 用的其实是不同配置，结果没法信。

---

## P3: 修复效果演示（~40s）

**画面**：[演示录屏] 从 Agent Build → Evaluate 开始

**口播**：现在点击 Run All 的时候，系统会自动锁定当前版本。我们来演示一下：先发起一次评测，然后故意去修改 Agent 配置。可以看到，评测结果完全不受影响，所有 case 用的都是启动时的那个版本。

**操作步骤**：
1. 进入 Agent Build 页面 → 点击 Evaluate
2. 点击 Run All → 确认运行
3. 等待评测完成，查看结果
4. 确认所有 case 结果一致

---

## P4: 结尾（~10s）

**画面**：v0.3.0 已发布 / 升级即可使用

**口播**：这个修复对单次和批量评测都生效。升级到 v0.3.0 就可以了，不需要做任何额外操作。
