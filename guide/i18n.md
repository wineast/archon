# 国际化（i18n）

Archon 使用 [next-intl](https://next-intl.dev/) 实现中英双语国际化。

## 基础概念

- **Locale**: `zh`（中文，默认）、`en`（英文）
- **URL 前缀**: 所有 locale 路由均带前缀，如 `/zh/admin`、`/en/admin`
- **非 locale 路由**: `/api/*`、`/embed/*`、`/share/*` 不带 locale 前缀

## 目录结构

```
web/
├── messages/
│   ├── zh.json          # 中文翻译
│   └── en.json          # 英文翻译
├── src/
│   ├── i18n/
│   │   ├── routing.ts   # defineRouting 配置
│   │   ├── request.ts   # 服务端 locale 解析
│   │   └── navigation.ts # locale 感知的 Link/useRouter/usePathname/redirect
│   ├── app/
│   │   ├── layout.tsx           # 根 layout（透传 children）
│   │   ├── [locale]/            # locale 动态段
│   │   │   ├── layout.tsx       # ClerkProvider + NextIntlClientProvider
│   │   │   └── ...              # 所有 locale 页面
│   │   └── (nonlocale)/         # embed/share（无 locale 前缀）
│   │       ├── layout.tsx
│   │       ├── embed/
│   │       └── share/
│   └── components/
│       └── locale-switcher.tsx  # 语言切换器
```

## 翻译文件

翻译文件位于 `web/messages/`，采用单文件嵌套 key 结构：

```json
{
  "common": { "save": "保存", "cancel": "取消" },
  "auth": { "signIn": { "title": "欢迎回来" } },
  "agent": { ... },
  "build": { ... }
}
```

**命名空间**:
- `common` — 全局通用词（保存、取消、删除等）
- `nav` — 导航标签
- `auth` — 认证页面
- `agent` — Agent 管理
- `build` — Build 页面 + 所有侧边栏
- `chat` — 聊天页面
- `admin` — 管理后台
- `org` — 组织设置
- `trash` — 回收站
- `share` — 分享页
- `embed` — 嵌入页
- 各领域 hooks（`datasets`、`tools`、`functions` 等）— toast 消息

## 使用方式

### 客户端组件

```tsx
"use client";
import { useTranslations } from "next-intl";

function MyComponent() {
  const t = useTranslations("build");
  const tc = useTranslations("common");
  return <p>{t("config")}</p>;
}
```

### 服务端组件

```tsx
import { getTranslations } from "next-intl/server";

export default async function Page() {
  const t = await getTranslations("agent");
  return <p>{t("noAgents")}</p>;
}
```

### Hooks 中的 toast 消息

Hooks 中的异步函数无法直接使用 `useTranslations`，通过可选参数传入 `t` 函数：

```tsx
// hooks.ts
export async function deleteAgent(id: string, mutate: ..., t?: (key: string) => string) {
  toast.success(t?.("movedToTrash") ?? "已移至回收站");
}

// 组件调用处
const tc = useTranslations("common");
deleteAgent(id, mutate, tc);
```

## 导航 API

locale 感知页面中，替换 `next/link` 和 `next/navigation` 为 `@/i18n/navigation`：

| 原导入 | 新导入 | 来源 |
|--------|--------|------|
| `Link` from `next/link` | `Link` from `@/i18n/navigation` | next-intl |
| `useRouter` from `next/navigation` | `useRouter` from `@/i18n/navigation` | next-intl |
| `usePathname` from `next/navigation` | `usePathname` from `@/i18n/navigation` | next-intl |
| `useSearchParams` | 保持 `next/navigation` | Next.js |
| `notFound` | 保持 `next/navigation` | Next.js |
| `redirect`（服务端组件） | 保持 `next/navigation` | Next.js |

## 语言切换器

`<LocaleSwitcher />` 组件放置在首页 header，使用 `useRouter().replace(pathname, { locale })` 切换语言。

## Clerk 本地化

在 `[locale]/layout.tsx` 中：
- `locale === "zh"` 时传入 `@clerk/localizations` 的 `zhCN`
- 英文时不传（使用 Clerk 默认英文）

## 新增翻译流程

1. 在 `messages/zh.json` 和 `messages/en.json` 中添加 key
2. 在组件中使用 `useTranslations("namespace")` 获取翻译函数
3. 用 `t("key")` 替换硬编码文本
4. 带参数：`t("key", { name: "value" })`（翻译文件中用 `{name}` 占位）
