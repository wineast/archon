# 用户权限管理 — 使用说明

---

## 一、角色概览

系统有两层角色：**平台角色**和 **Agent 角色**。

### 平台角色

| 角色 | 说明 |
|------|------|
| **超级管理员** | 拥有所有 Agent 的最高权限，可管理平台用户 |
| **普通用户** | 默认角色，只能访问被授权的 Agent |

### Agent 角色

每个 Agent 独立管理成员，四级角色从高到低：

| 角色 | 一句话定位 |
|------|-----------|
| **拥有者 (Owner)** | 完全控制，包括删除 Agent 和转让所有权 |
| **管理员 (Admin)** | 管理配置和成员，不能删除 Agent |
| **编辑者 (Editor)** | 编辑 Agent 的所有配置内容 |
| **使用者 (Viewer)** | 只能与 Agent 聊天 |

---

## 二、各角色能做什么

### Owner — 拥有者

拥有该 Agent 的一切权限：
- 修改 Agent 名称、图标、描述
- 删除 Agent
- 邀请/移除成员，修改任何人的角色
- 将 Owner 转让给其他成员
- 切换 Agent 的公开/私有模式
- 编辑所有配置（提示词、工具、Wiki、模板变量、码表、数据对象、评估等）
- 与 Agent 聊天，查看所有用户的聊天记录

### Admin — 管理员

除了不能删除 Agent 和转让 Owner，其余与 Owner 相同：
- 邀请/移除成员（不能操作 Owner）
- 修改成员角色（不能将他人设为 Owner）
- 切换公开/私有模式
- 编辑所有配置
- 查看所有用户的聊天记录

### Editor — 编辑者

专注于 Agent 内容编辑：
- 编辑模型配置、系统提示词
- 编辑模板变量、码表、数据对象
- 编辑 Wiki 文档
- 添加/修改/删除工具
- 编辑评估用例、运行评估
- 编辑 Chat UI 配置
- 与 Agent 聊天，查看自己的聊天记录
- **不能**：管理成员、修改 Agent 基本信息

### Viewer — 使用者

仅限聊天使用：
- 与 Agent 聊天
- 查看、删除、分享自己的聊天记录
- **不能**：查看或修改任何配置

---

## 三、Agent 访问模式

| 模式 | 行为 |
|------|------|
| **私有**（默认） | 只有被邀请加入的成员才能看到和使用该 Agent |
| **公开** | 所有已登录用户都能以 Viewer 身份使用该 Agent |

Owner 和 Admin 可以在 Agent 设置中切换访问模式。

---

## 四、常见操作

### 4.1 创建 Agent

任何已登录用户都可以创建 Agent，创建者自动成为该 Agent 的 Owner。

### 4.2 邀请成员

1. 进入 Agent 配置页 → 「成员」Tab
2. 输入对方的注册邮箱
3. 选择角色（Admin / Editor / Viewer）
4. 点击邀请

> 被邀请的用户必须已经注册过账号，邀请后对方立即可以在 Agent 列表中看到该 Agent。

### 4.3 修改成员角色

1. 进入「成员」Tab → 找到目标成员
2. 点击角色下拉菜单，选择新角色
3. 变更立即生效

**限制**：
- 不能修改 Owner 的角色（需通过"转让"操作）
- Admin 不能将其他人设为 Owner

### 4.4 移除成员

1. 进入「成员」Tab → 找到目标成员
2. 点击移除按钮 → 确认
3. 该用户立即失去对 Agent 的访问权限

### 4.5 转让 Owner

1. 进入「成员」Tab → 找到目标成员
2. 点击「转让拥有者」
3. 确认后，对方成为新 Owner，你降级为 Admin

> 每个 Agent 有且只有一个 Owner。

### 4.6 切换公开/私有

1. 进入 Agent 配置页 → 「访问设置」
2. 切换公开/私有开关

- 设为公开：所有登录用户可作为 Viewer 使用
- 设为私有：仅成员列表中的用户可访问

---

## 五、聊天记录可见性

| 你的角色 | 能看到的聊天记录 |
|---------|----------------|
| Viewer / Editor | 仅自己的 |
| Admin / Owner | 可切换查看所有用户的 |

- 每个用户的聊天记录相互隔离，默认只看到自己的
- Admin 及以上可以在聊天记录列表中切换「我的记录」/「全部记录」
- 分享链接（Share）不受角色限制，任何人（包括未登录用户）都可以通过分享链接查看

---

## 六、超级管理员

超级管理员拥有平台级特殊能力：

- 对所有 Agent 拥有隐式 Owner 权限，无需被邀请
- 可在后台管理用户列表
- 查看平台统计数据

超级管理员由现有超级管理员通过后台授予，普通用户无法自行升级。

## 八、FAQ

**Q: 我创建的 Agent 别人能看到吗？**
新创建的 Agent 默认为私有模式，只有你（Owner）能看到。需要手动邀请成员或设为公开。

**Q: 我被移除了还能看到之前的聊天记录吗？**
不能。被移除后你将无法访问该 Agent 的任何内容，包括你自己的历史聊天记录。

**Q: Viewer 能看到 Agent 的提示词和工具配置吗？**
不能。Viewer 只能看到聊天界面，所有配置页面对 Viewer 隐藏。

**Q: 我可以同时是多个 Agent 的 Owner 吗？**
可以。Agent 角色是按 Agent 独立分配的，你可以在不同 Agent 上拥有不同角色。

**Q: 公开 Agent 的访客能修改配置吗？**
不能。公开模式只赋予 Viewer 权限，即只能聊天。如果需要编辑权限，必须由 Admin 以上角色显式邀请。

**Q: 转让 Owner 后我还能管理成员吗？**
可以。转让后你自动降级为 Admin，仍然保留成员管理权限。
