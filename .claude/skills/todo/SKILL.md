待办事项管理技能——在 `todo/` 目录下维护待办列表。

## 触发条件

当用户提到以下任意表述时，应调用此技能：
- "记个待办"、"加个 TODO"、"先记下来以后做"
- "查看待办"、"有哪些待办"
- "完成了"、"这个做完了"、"勾掉"
- "待办列表"、"TODO 列表"

## 与 Issue 的区别

- **Issue**：有分析、有涉及文件、有修复方向，适合 bug 和需要调研的问题
- **Todo**：一句话待办，快速记录，适合小任务、提醒、后续要做的事

## 目录结构（文件夹即状态）

```
todo/
  pending/      ← 待办
  done/         ← 已完成
```

- 一个待办一个文件，文件通过所在文件夹表示状态
- 状态变更 = 移动文件到对应文件夹

## 待办文件规范

- 文件名格式：`{简短描述}.md`，用英文短横线连接
- 内容简洁，一两句话说清楚即可

### 模板

```markdown
# {标题}

{补充说明（可选）}
```

## 操作流程

### 添加待办

1. 确保 `todo/pending/` 目录存在
2. 创建文件到 `todo/pending/`
3. 确认：`已添加待办 — {内容}`

### 查看待办

列出 `todo/pending/` 下所有文件。

### 完成待办

将文件从 `todo/pending/` 移动到 `todo/done/`：
```bash
mv todo/pending/{name}.md todo/done/
```

### 删除待办

直接删除文件。

## 注意事项

- 保持简洁，todo 不需要详细分析
- 文件名不带编号
- 状态完全由文件夹决定
